## 5.0日常使用

- 顶栏只保留一个同步状态：绿点表示最近更新正常，琥珀色显示异常来源数，更新时出现进度条。点击后可以更新关注人物或全部41人、查看失败来源，或进入来源管理。
- 搜索和快捷筛选只在工作台、收件箱、核验队列和人物页出现；来源、简报、预测、设置等页面不再重复显示。保存的研究视图并入快捷筛选行，“保存为研究视图”在筛选面板里。
- 列表卡片显示整理后的标题，例如去掉“ - Yahoo Finance”这类媒体后缀；媒体名单独显示。摘要只是重复标题时不再显示，排序依据在鼠标悬停时显示。
- 收件箱右上角可选“卡片／列表”。列表一行一条，适合快速浏览；选择记在本浏览器。
- 键盘：J／K移动光标，Enter或O打开，R切换已读，S收藏，X勾选；勾选后底部出现批量栏，可标已读、标未读、收藏或加入对照。Z撤销上一步，Esc取消勾选。
- 阅读面板先显示标题、日期、出处和摘要，接着是“留下我的判断”；整理依据与主题建议收在可展开区域。L稍后核验；勾选“已读后跳到下一条”后，按R会自动打开下一条。
- 核验队列点击“连续核验”：一次只显示一条，O打开原文；1“我已核对原文与上下文”，2稍后复核，3排除无关，4疑似重复，→跳过，E深入评估。每一步都以追加记录保存，可用Z撤销。“已核对”只在你主动选择后记录为用户核验，原始材料不会被修改。
- 工作台显示距上次打开的新增材料（间隔30分钟以上算新的一次打开）、关注人物动态卡片、五项关键数字、优先阅读与专注阅读进度。侧栏和标签栏上的核验数字只统计关注人物。
- 人物卡片显示近8周材料数的小柱图、未读数和最近日期，可按关注、最新动态、未读或姓名排序。来源管理按人物分组列出状态、域名和最近结果，可筛选“只看失败”等。每日简报先列出六项统计，再按人物分两栏列出已核查材料与公开线索。
- 手机：底部标签栏为工作台、收件箱、核验、人物和更多；筛选面板从底部弹出；向下滚动时顶栏自动收起。

收件箱显示方式、自动跳转、人物排序和“上次打开”时间只保存在当前浏览器（新键 investor-research-desk-ui-v5），不进入完整研究JSON。

## 4.0日常使用

- 首页先显示一条优先材料，再展示研究主题与后续队列。排序依据可见；主题是关键词建议，不是事实核验或作者观点结论。
- “开始一轮阅读”按当前范围选择5、10或15组未读材料。队列保留在当前浏览器，当天可继续；仅标记已读才计入进度。重新开始使用当前筛选，调整每轮数量不改变进行中的队列。
- 阅读面板点击专注图标或按F，扩大阅读区并展示证据缺口与同人物材料。手机将研究提示置于正文之后。R切换已读，S切换收藏，J／K切换材料；输入框内不触发这些快捷键。
- 笔记草稿自动保留，成功后可直接切换或关闭，再回来会恢复。浏览器存储失败时阻止切换；“正式保存”才追加研究评估记录。草稿、阅读队列和界面偏好不包含在完整研究JSON里。
- “保存研究视图”保留人物、关键词、日期、类型、版本和排序，最多12个。视图名称出现在搜索区；再次打开保存窗口可删除视图。当前筛选有独立移除按钮。
- 在材料右侧点击双栏图标选择两条，再点击“并排对照”。人物、时间、状态、标的、期限、笔记等逐项显示；只高亮字段差异，不自动推断作者立场冲突。
- Ctrl／⌘ K打开快捷操作，↑↓移动选择、Home／End跳转、Enter执行。顶栏月亮／太阳图标切换浅色与深色界面。
- 最新记录、全部历史与核验队列使用一致的条件搜索。历史排除记录仍可查看，原始资料没有删除。

界面偏好、研究视图、队列和草稿依赖当前浏览器存储。移动到另一台电脑时，正式保存重要笔记并导出完整JSON；已有档案继续使用原存储键与schema 2。

## 3.0更快的使用方式

- 今日工作台：按关注、未读、材料日期与出处状态整理优先阅读列表，并展示阅读、核验、近期材料和到期复盘的下一步入口。
- 快捷筛选：优先阅读、只看关注、未读、AI基建、收藏、已核验出处与全部材料。搜索可输入“关注 未读 近7天 AI”；识别的条件会在输入框下显示，普通关键词继续检索人物、标题与摘要。
- 侧边阅读：从材料标题打开，原文入口、三个日期、整理依据、主题建议和个人判断集中展示；支持收藏、标已读、稍后核验和排除无关。
- 研究笔记：输入时自动保留本浏览器草稿，点击“正式保存笔记”才进入档案与JSON备份。切换／关闭阅读面板会保护尚未保存的笔记。草稿不随档案JSON备份同步，换设备前应正式保存。
- 撤销：阅读面板的收藏、已读、个人立场和队列标记，以及当前显示材料的批量标已读，提供一次撤销。队列／判断撤销追加版本，原历史仍保留。
- 分步评估：出处与命题先展开，仓位、时效和交叉证据按需展开；保存前的提示只检查信息完整性，不认定事实为真。
- 重复合并：同人物的相同规范链接或完全相同标题合并展示，原始来源记录全部保留；不是全文语义去重。
- 人物研究：关注人物优先，支持卡片与紧凑列表。手机可通过工作空间选择器进入来源、设置与方法说明。
- 快捷键：/搜索；Ctrl／⌘ K打开快捷操作；阅读面板内J／K下一条／上一条；Esc关闭面板。

自动主题建议与优先级使用公开可见的本地规则，不调用大模型，不会自动提高核验状态，也不预测投资收益。具体周期、首次启用和核验队列见更新计划.md。

## 本地服务（推荐）

先解压整个包。需要Python 3.9或更新版本，无需pip。

- Windows：双击start-windows.bat。
- macOS：运行start-macos.command；无执行权限时在终端执行bash start-macos.command。
- Linux：python3 server.py。

浏览器打开http://127.0.0.1:8765/。保持启动窗口打开。新版服务版本为2.0；若原26人服务占用端口，应先关闭原服务窗口，或运行python server.py --port 8766。用新端口打开页面时自动采用该服务地址。

“更新与备份 → 同步本地档案”合并采集器写入的新记录；“保存到本地JSON”把网页新增观点、评估、预测、关注和设置写入文件。浏览器修改不会悄悄改写磁盘；文件发生并发更新时拒绝覆盖，先同步再保存。

data/state.json是事务主档案；people、sources、timeline、scorecard是可单独检查的同步导出。写入保留历史数组、检查版本、加进程锁并原子替换；state.previous.json保存前一次快照。不要同时手工编辑分文件并期望自动合并进state.json。

## 工作流程

1. 看板中选择人物，查看待核验资料、专长与来源；“档案／核验”可追加事实及证据，确认出生日期后计算年龄。
2. 在来源目录启用、检查或添加RSS／Atom。普通网页不是RSS。综合机构RSS不能自动归为个人言论；设作者筛选时，没有作者字段的条目不归给该人物。
3. 公开线索或原稿需要核对原文。录入观点时分开填写本人表态日期和来源发布日期；未知日期可空。
4. “追加修订”保留原记录，“五步处理”保存独立评估版本。立场对照需相同主题、标的和期限，条件仍需人工比较。
5. 登记明确预测后，原规则锁定。自动试算需实际结果数据，人工复核后才进入统计。历史补录排除前瞻排名，不用模糊原话自动造量化承诺。
6. 定期导出完整JSON；CSV可导出筛选后的观点或预测，包含版本与日期。

## 每日采集

手动运行run-fetch-windows.bat，或bash run-fetch-macos.command。对应命令：

python tools/fetch_feeds.py --all --prices --brief

采集器独立运行，不需要网页打开或服务运行。默认检查全部41人的已启用公开来源，写入本地JSON和reports/daily-YYYY-MM-DD.md每日简报；有启用的结果CSV来源时同时抓取并对到期预测试算。网络失败会写明原因，不删除旧记录或伪造新鲜度。

只检查关注人物：python tools/fetch_feeds.py 。

检查单人：python tools/fetch_feeds.py --person marks 。

指定资料目录：python tools/fetch_feeds.py --all --data-dir /your/data 。

Windows可选择运行install-daily-task.ps1创建当前用户每天08:30的计划任务。时间采用电脑本地时区，任务在用户已登录且电脑可运行时执行，不承诺关机状态持续采集；记录在fetch-log.txt。安装失败不会影响手动采集。删除任务可在任务计划程序删除InvestorResearchDeskDaily。

macOS/Linux可自行把run-fetch脚本加入系统计划任务；例如每天08:30执行python3 /absolute/path/tools/fetch_feeds.py --all --prices，工作目录及文件路径使用解压后的实际位置。

## EDGAR与公开结果数据

预设Berkshire Hathaway CIK 1067983的机构备案入口，默认未启用。SEC采集需要真实名称与联系邮箱的User-Agent，在设置中填写、保存本地JSON后启用。该字段仅发送给SEC，不发送给其他RSS或中转；备份含你填写的联系信息，分享备份前自行检查。

新增SEC来源需CIK与法律主体英文全名，返回名称不匹配时拒绝归档。备案归为机构披露，不当作巴菲特等人的个人观点。13F信息表尚未自动解析到完整持仓对照矩阵；本版获取备案及报告期，仓位一致性仍通过证据链接和人工评估核对。

结果CSV列为symbol,date,value,currency,sourceUrl,adjustment；空白模板可在预测记分卡下载。来源地址必须公开HTTPS，手工CSV每条也需出处链接；不预设未经验证的免费行情接口、不需要交易账户或API密钥。

可以添加符合上述CSV格式的公开HTTPS结果来源，保存本地JSON后由定时采集器获取。或运行：

python tools/fetch_feeds.py --import-prices your-results.csv --prices

未到期不结算；到期没有匹配币种、口径及观察日的数据时显示缺数据。规则采用到期日前7天内最近观察，原始规则与结果来源可回溯。评分不是投资胜率，命中率不是投资收益。

## 每日简报与待核验队列

简报日期使用北京时间，分别统计当天新增收录、当天表态／发布、历史补录和材料日期未知。近7天的已核查出处／用户核验材料与未核验公开线索分开显示，各展示最多20条，完整记录在时间轴。来源状态展示当前最近检查，不声称回溯该日期的历史连接状态。

“待核验队列”优先关注人物、争议及重大事项，支持稍后复核、排除无关、疑似重复或恢复待核验；排除时需备注。标记是追加记录，原始材料不会删除，核验状态不会自动变更；新修订版本需重新处理。可导出队列CSV，或跳到五步处理核对出处。

网页可导出按当前人物筛选生成的Markdown简报。采集器增加--brief后在reports生成全名单简报；单独生成无需联网：python tools/brief.py。每日脚本已包含--brief。

## 常见问题

- 页面没有“新观点”：看来源获取状态，区分成功0条、作者筛选不匹配和网络失败。
- 新采集没有出现在网页：点击“同步本地档案”；浏览器缓存与磁盘是两个工作空间。
- 保存报409：采集器或另一页已更新文件，先同步再保存；不会覆盖旧文件。
- 浏览器缓存报错：立即导出JSON，不清空历史；可改用本地服务保存。
- 无法访问Google News：本地服务也不能消除外网可达性限制，可使用能访问的官方RSS和人工录入。
- 403/429：访问被拒或限流，保留失败状态，稍后再试或直接阅读平台；不绕过访问限制。
- 无排名：需同领域、同期限的已复核前瞻样本，默认至少20条才有排名资格。
